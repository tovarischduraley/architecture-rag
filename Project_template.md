# Задание 1. Исследование моделей и инфраструктуры

## 1. Сравнение LLM-моделей

| Критерий           | OpenAI GPT-5 / GPT-4 | YandexGPT 5.1    | Hugging Face                      |
|--------------------|----------------------|------------------|-----------------------------------|
| Качество ответов   | Отличное             | Хорошее          | Зависит от модели, в среднем хуже |
| Скорость           | Высокая              | Высокая          | Средняя                           |
| Стоимость          | Платная, за токены   | Бесплатная       | Бесплатная, но требует сервер     |
| Развёртывание      | API                  | API              | Нужны ресурсы и знание моделей    |
| Конфиденциальность | Утекает в облако     | Утекает в облако | Можно держать локально            |

## 2. Сравнение эмбеддингов

| Критерий          | OpenAI Embeddings | Sentence-Transformers |
|-------------------|-------------------|-----------------------|
| Качество          | Отличное          | Хорошее               |
| Скорость создания | Высокая           | Зависит от железа     |
| Стоимость         | Платно            | Бесплатно             |
| Приватность       | Нет               | Да                    |

## 3. Сравнение векторных баз FAISS и ChromaDB

| Критерий            | FAISS                 | ChromaDB                                 |
|---------------------|-----------------------|------------------------------------------|
| Скорость поиска     | Очень высокая         | Высокая                                  |
| Индексация          | Быстрая               | Быстрая                                  |
| Хранение метаданных | Ограниченное          | Расширенное (есть фильтрация, TTL и др.) |
| Поддержка           | Старый проект от Meta | Новый и активно развиваемый              |
| Установка           | Простая               | Простая                                  |
| Сложность           | Низкая                | Средняя                                  |

## 4. Рекомендованная конфигурация сервера

Для локального RAG-бота с Sentence-Transformers + FAISS + HuggingFace LLM:

- CPU: 4-8 vCPU
- RAM: 16-32 GB
- GPU (опционально): NVIDIA RTX 3070 или выше
- Хранилище: SSD, от 64 GB

## Итоговые варианты

| Вариант                                                        | Описание                                          | Плюсы                                  | Минусы                     |
|----------------------------------------------------------------|---------------------------------------------------|----------------------------------------|----------------------------|
| 1. Облачный (OpenAI + OpenAI Embeddings + FAISS)               | Всё в облаке                                      | Высокое качество, быстрое время ответа | Стоимость, нет приватности |
| 2. Локальный (Sentence-Transformers + FAISS + HuggingFace LLM) | Всё локально                                      | Безопасность, контроль                 | Сложность, железо          |
| 3. Гибрид (OpenAI LLM + локальные эмбеддинги и FAISS)          | Приватность эмбеддингов, хорошее качество ответов | Баланс между качеством и приватностью  | Сложнее настроить          |
